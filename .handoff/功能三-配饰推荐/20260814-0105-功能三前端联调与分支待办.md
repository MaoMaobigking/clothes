## 已知陷阱

### 功能三业务侧

- 工作区同时存在功能二和功能三购物车同名文件时，不要用 `cartRepo/cartService/cart` 再覆盖功能二文件。
- PowerShell 引用 stash 必须用单引号：`git show 'stash@{0}'`，否则 `@{0}` 会被解析掉。
- 旧服务 `8787/8788` 没有最新配饰路由，不能只看端口通了就认为 API 是最新代码。
- `uni.request` 在 H5 和小程序原生模式的 base URL 分支要分别检查，避免只修了一个。
- 配饰页面进入时若没有上下文会弹出服装选择器；从商城入口进入时不要调用“服装入车”接口，商城商品不是当前用户的衣橱行。
- 小程序样式隔离：页面 wxss 穿不透自定义组件，给 `<tile-image>` 加 class 只会落在宿主节点，样式修复必须写进组件内部。

### 小程序自动化验收侧（本轮踩完的坑，下次直接照做）

- **`miniprogram-automator` 0.12.1 与工具 2.01.2510290 的 Page 域协议不兼容**：`page.$`、`$$`、`data()`、`callMethod()`、`wxml()` 全部超时。能用的只有 `mp.evaluate`、`mp.screenshot`、`mp.systemInfo`、`mp.currentPage`、`mp.pageStack`、`mp.reLaunch`。所有断言都要走 `mp.evaluate`。
- 连接前必须打补丁，否则版本校验直接抛错（`Tool.getInfo` 只返回 `{version}`，没有 `SDKVersion`）：`import MiniProgramMod from 'miniprogram-automator/out/MiniProgram.js'` 之后 `MiniProgramMod.default.prototype.checkVersion = async () => {}`。
- **不要用 `automator.launch`**：Node 22 拒绝 `spawn` 一个 `.bat`（除非 `shell: true`）。正确姿势是先 `cli.bat auto --auto-port 9420` 把 IDE 拉起来，再 `automator.connect({ wsEndpoint: 'ws://127.0.0.1:9420' })`。
- **IDE 服务端口有闸门文件**，卡住时报「IDE may already started at port xxxxx」→「wait IDE port timeout」。清理：`taskkill //F //IM wechatdevtools.exe`（只杀自己的），然后删
  `%LOCALAPPDATA%\微信开发者工具\User Data\97c2c3ed9e9b4a343745d4ac3603eef1\Default\` 下的 `.ide`、`.ide-status`、`.cli`。刚清完立刻连会 `ECONNRESET`，等 IDE 起来再连。
- **同一个 appid 的第二个项目路径打不开**：换路径开会报 `TypeError: d.on is not a function at openOrCreateWindow`。绕法是不换路径——把 dev 产物拷进已注册的那个路径（本轮就是 `rm -rf dist/build/mp-weixin && cp -r dist/dev/mp-weixin/. dist/build/mp-weixin/`，所以 **`dist/build/mp-weixin` 目前装的是 dev 产物**，要正式产物就重跑 `build:mp-weixin`）。
- **uni-app mp 的 `setupState` 永远是空的**：模板被编译成 setup 闭包里的取数函数（`setup()` return 的是 `{a: ..., b: common_vendor.p({...})}`），dev 和 production 都一样。想驱动页面只能：
  - 读数据 → `getCurrentPages().at(-1).data`（里面就是真实文案/名称/分数/理由）；
  - 触发事件 → `common_vendor.o(fn, key)` 把 handler 注册成**页面方法**，`data` 里存的是方法名字符串（如 `"e2_jewelry"`、`"84cdac32-1-0"`），所以 `page[name](evt)` 直接调即可。
  - `.tmp/mp-qa/map-handlers.mjs` 是从编译产物里提 `data key → handler` 映射的小工具。
- **测 TileImage 内部盒模型要用 `>>>` 跨组件边界**：`wx.createSelectorQuery().selectAll('.accessory-image >>> .tile')`。`<tile-image>` 标签上没有 class，只能从父级下钻。
- **截图截不到首屏以下**：正文是 `<scroll-view scroll-y>`，`wx.pageScrollTo` 对它无效；`ScrollViewContext.scrollTo`（`select('.body').node()`）要求 scroll-view 带 `enhanced` 属性才生效。本轮的办法是**只改打包产物**（`dist/.../pages/accessory/index.wxml` 临时加 `enhanced scroll-top="{{__qaTop}}"`），再用 `page.setData({__qaTop})` 驱动，拍完把产物还原（源码没动）。首屏以下的断言不依赖截图，靠 selectorQuery 几何 + `page.data`。
