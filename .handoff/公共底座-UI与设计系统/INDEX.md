# 公共底座 · UI 与设计系统交接索引

> 接手先读本文件，再按需展开单份文档。别一次全读。

本目录覆盖跨功能的 UI 层：视觉语言、图标体系、全局样式管理。
不属于任何单一功能，但六个功能的页面都长在这套底座上。

⚠️ **现行视觉语言是 `@climblee/uv-ui` 自己的那套。**
原来的 8 张设计稿和 `wechat-app-mall` 两套参考**都已作废**，
但设计稿里的**结构性要求**（哪一页有哪几块、怎么排）仍然保留。
