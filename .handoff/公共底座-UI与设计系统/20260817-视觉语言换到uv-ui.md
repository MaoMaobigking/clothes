# 视觉语言换到 uv-ui：设计稿作废、白屏修复、玻璃 / 马卡龙局部层

> 2026-08-17 ｜ 依据：用户三轮口头指令（见下「为什么这批必须做」）
> 覆盖 `ff3452b` + `580e4c6` + 本次提交，三轮连续改动

## 一句话

**两套旧参考（8 张设计稿、`wechat-app-mall`）全部作废**，视觉语言改为跟随
`@climblee/uv-ui` 自己的设计语言（粉 `#ff5c9d` + 冷灰底 + 发丝线 + 无阴影）；
换皮过程中暴露并修掉了「全站白屏」和「`--btn-h-*` 从未生效」两个隐蔽 bug；
第三轮在这套冷调地基上，**局部**加了玻璃卡和马卡龙胶囊两个例外层。

## 为什么这批必须做

三轮指令是递进的，后一轮修正前一轮，所以必须按顺序读：

**第一轮（→ `ff3452b`）**：设计稿和商城参考都不要了，「按 uv-ui 自己的设计语言来」。
即：主色 `#ff5c9d`、页面底 `#f3f4f6` 冷浅灰、文字走 uv-ui 的四档冷灰、
**分隔用发丝线不用阴影**、不要渐变、按钮不要投影、结构分页型
（列表页 → `uv-cell` 发丝线；内容页 → 卡片网格）。

**第二轮（→ `580e4c6`）**：情景模拟和自由搭配按样图重排；
「我的」页面那些点了没反应的按钮，**要么接上要么置灰**；
人台先删掉（素材没到位），后续再加；只显示样图上画了的功能，其余隐藏不删。

**第三轮（→ 本次）**：情景模拟页太素，天气卡要玻璃质感，小按钮要马卡龙果冻感。
这一轮**不推翻第二轮** —— 页面底还是冷灰、`.card` 还是白底发丝线、
正文按钮还是无阴影，玻璃和马卡龙只在指定位置出现。

## 改了什么

### 1. `ff3452b` — 视觉语言整体换到 uv-ui（67 文件，+1362/-884）

| 层 | 改动 |
|---|---|
| `src/uni.scss` | 定义 uv-ui 的 SCSS 主题变量（`$uv-primary` 等）。uv-ui 的变量都带 `!default`，同名定义即覆盖 |

### 3. 本次提交 — 玻璃 / 马卡龙层 + px→rpx + 类型修复（16 文件，+566/-170）

**玻璃卡 `.card-glass`**（`components.css`）—— 从「白底 + 发丝线 + 浮起阴影」
改成真玻璃：

```css
background-color: var(--glass-bg);      /* rgba(255,255,255,0.72) */
background-image: var(--glass-tint);    /* 粉 8%0% / 薄荷 100%100% 两团径向光晕 */
border: 0.5px solid var(--glass-line);
box-shadow: var(--shadow-glass), var(--glow-inset);
backdrop-filter: var(--glass-blur);
```

`background-color` / `background-image` 拆开写是必须的 —— `background` 简写会
把另一层重置掉。它是**修饰类**，用法是 `class="card card-glass"`。

**马卡龙胶囊 `.pill-macaron`** + 三个配色修饰（pink / mint / violet），
带 `--shadow-jelly`（内上高光 + 内下暗边 + 外投影）。
三组底色 / 字色都反算过 WCAG AA 对比度（正文级 24rpx，按 4.5 收不按大字的 3.0）：

| 修饰 | 底 | 字 | 对比度 |
|---|---|---|---|
| `.pill-macaron-pink` | `#ffe3ee` | `#b82a5f` | 4.94:1 |
| `.pill-macaron-mint` | `#ddf6ea` | `#0f7a58` | 4.68:1 |
| `.pill-macaron-violet` | `#ebe6ff` | `#5442b5` | 6.13:1 |

⚠️ **这是全站唯一带阴影的按钮形态**，是刻意的例外。边界写在
`components.css` 的注释里：正文 CTA 和 chip 仍然无阴影，别扩散。
`UiIcon` 同步加了 `macaron-pink|mint|violet` 三个 tone（色值和上表字色同值，
改一边记得改另一边）—— 马卡龙底色上配默认灰图标会显得没做完。

**落地位置**：`scene/SceneWeather.vue` 的天气卡（`card card-glass`）、
`wc-locate` / `wc-manual` 两个按钮（violet / pink）、`scene/index.vue` 的
`wc-diary`（mint）、`home.vue` 的 `.weather` 胶囊。

**px → rpx**：`scene/index.vue` 56 处、`SceneWeather.vue` 25 处，全部按 ×2 换算；
另外把全站 8 处 `TileImage` 的 `rounded="Npx"` 也换成 rpx
（community 4 / home 2 / my-favorites 1 / outfits 1）。

**衣橱左栏改浮层抽屉**（`pages/closet/closet.vue`）—— 原来分类栏是 Flex 列里的
`scroll-view`，和右侧网格平级、共享横向空间。改成 `position: absolute` +
`--shadow-float` 的浮层抽屉后，右侧网格滚动时它稳稳不动。三个约束写在注释里：
`z-index` 走 `--z-float`(10) 而不是随手写数字（衣橱是 tabBar 页，
底部导航是 `--z-sticky`(20)，抽屉必须**低于**它，否则滚到底会盖住导航）；
抽屉宽度和把手左偏移共用 `--rail-w` 一个变量（分开写下次调宽度必漏一个）；
**把手留在 Flex 流里不跟着浮起**，它是「抽屉在哪、怎么开合」的唯一线索。
选中态圆角从 `--radius-sm`(6rpx) 提到 `--radius-lg`(16rpx) —— 6rpx 看着像被选中的
表格单元格，不像高亮胶囊；不用 `--radius-pill`(9999rpx)，那会在 118×80rpx 的格子上
圆成一坨药丸。**没有自造 20rpx 之类的中间值，圆角必须留在 tokens 那四档里。**

**`TileImage` 加载中占位**（`components/TileImage/TileImage.vue`）——
`show-loading` 从 `false` 改回 `true`，但内容由 `#loading` 插槽自己给
（同一个 `UiIcon`、同图标同色同粗细）。原来关掉它的理由是 uv-image 自带的
loading 图标是 uvicons 字体图标、和本项目线条风格不是一套 —— 有插槽之后这个理由
不成立了。关着的话加载期间是一片纯空白再突然淡入，慢网大图上很明显；
现在的过渡是「占位淡出 → 图淡入」。`show-error` 仍然关着，失败一律回退到
`showPlaceholder`，保持全站占位形态统一。

## 顺带修掉的现存 bug

1. **全站白屏（`ff3452b` 里修的，最贵的一个）** —— 换 uv-ui 时删掉 84 处显式组件
   `import` 是**必须**的，不是顺手清理：uni-app 编译组件路径 marker 时有前向引用
   bug，显式 import 会让整个小程序白屏，且控制台没有有效报错。
2. **`--btn-h-sm/md/lg` 从来没定义过** —— `pages/scene/index.vue` 里有 **10 处**
   `height: var(--btn-h-sm|md)` 在引用它们。CSS 变量未定义 → 整条声明作废，
   所以那些按钮一直是内容撑起来的高度，从来没按设定值走过。
   本次在 `tokens.css` 里补上（60 / 80 / 100rpx，对齐 uv-button 的 small/normal/large
   三档 30/40/50px）。和上一轮 `--surface-tint` 的 25 处死引用是同一类 bug。
3. **`.body` 本地遮蔽全局 token** —— `scene/index.vue` 的 `.body` 里本地声明了
   `--btn-h-sm: 60rpx; --btn-h-md: 72rpx;`。CSS 自定义属性在 scoped 选择器上会
   遮蔽 `page` 上的全局声明，留着的话这一页的功能按钮永远比全站矮 8rpx ——
   又变回「同一个变量两个值」。已删掉本地声明，md 从 72 → 80rpx 是刻意对齐。
4. **`vue-tsc` 有 3 个错，本次修掉** —— 详见下面「验收状态」，这是本批引入的回归。
5. **写死颜色残留** —— `SceneWeather.vue` 的 `linear-gradient(150deg,#c9ecff,#b8b0ff,#ffc9e8)`
   和 `.manual-panel` / `.manual-input` 的 `rgba(255,255,255,0.58|0.86)` 是第二轮
   漏掉的；`home.vue` `.weather` 的 `rgba(255,255,255,0.7)` 是渐变底时代的遗留。
   都已换成变量。

## 6 个不显然的坑（改之前请先读）

1. **安卓微信小程序没有 `backdrop-filter`。** 玻璃质感不能靠模糊撑 ——
   撑住它的是 `--glass-tint` 那两团粉 / 薄荷光晕，模糊只是 iOS / H5 的加分。
   所以玻璃卡上**不要放浅灰小字**，最弱的一档只到 `--text-3`
   （`.wc-date` 就是按这条定的）。降级结果是「半透明白 + 两团光晕」，
   是可接受的形态，不是坏了。

2. **发丝线必须留 px，不能换 rpx。** `--hairline` 是 `0.5px`。分隔线不应该
   跟着屏宽缩放；而 `1px` 在 2 倍屏上是两个物理像素，和 `uv-cell` 并排会
   明显粗一档（`me.vue` 的 `.menu-item` 就是因为这个从 1px 改成 `var(--hairline)`）。

3. **`rpx` 可以和 `env()` 混在 `calc()` 里**，WXSS 支持。
   `padding: 36rpx 32rpx calc(36rpx + env(safe-area-inset-bottom, 0px));` 是有效写法。
   env 的**兜底值**保持 px（`0px` / `12px`），那是物理安全区概念，不该缩放。

4. **scoped 规则会盖掉全局类。** `SceneWeather.vue` 的 `.wc-locate` / `.wc-manual`
   现在只留 `flex-shrink: 0`，尺寸 / 圆角 / 底色 / 字色 / 果冻投影**一条都不重复写** ——
   scoped 的特异性比全局单类高，写了就是把 `.pill-macaron` 盖掉。

5. **`uni.scss` 里的 `$show-border*` / `$show-lines` 开关必须定义**，否则 uv-ui
   的边框 / 截断工具类根本不生成 —— 静默失败，表现是 `uv-tabbar` 的发丝线和
   所有 `uv-cell` 分隔线全部消失。

6. **uni-app 给 `<button>` 注入了默认 `::after` 伪边框**
   （`1px solid rgba(0,0,0,.2)` + `border-radius: 10px`）。在 9999rpx 的胶囊上，
   那个 10px 圆角方框会从胶囊里露出四个角。`.pill-macaron::after { border: none }`
   就是干这个的，新写胶囊按钮记得带上。

## 环境与复现

```bash
cd miniapp
npx vue-tsc --noEmit          # 期望 exit 0、无输出
npm run build:mp-weixin       # 期望 exit 0、DONE Build complete.
# 微信开发者工具导入 miniapp/dist/build/mp-weixin
```

⚠️ 必须 `build:mp-weixin` 而不是 `dev:mp-weixin` —— dev 的产物落在 `dist/dev/`，
开发者工具按上面的路径永远读不到，会看着像「改了没生效」。

⚠️ shell 陷阱：`cmd 2>&1 | tail -5; echo $?` 拿到的是 `tail` 的退出码。
要判构建成败得写 `cmd > log 2>&1; echo $?`。
