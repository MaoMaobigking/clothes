# 图片素材清单

> 版本：v1.0　日期：2026-08-16　依据：`docs/六功能需求规格与验收清单.md` §14
> 用途：把代码里已经预留好路径、但素材还没到位的图集中列出来，交给素材同学一次配齐。

## 怎么用这份清单

- **路径就是约定**。代码里已经按下表的路径去取图，图片按文件名丢进对应目录即可生效，**不需要改代码**。
- **缺图不会报错也不会白块**。所有位置都做了中性占位回落（色块 + emoji / 渐变底 / 「暂无素材」文案），
  符合 §14「缺失素材时显示中性占位，不使用卡通图替代」。
- **目录根**：`miniapp/src/static/`。表里的路径都是运行时路径（以 `/static/` 开头），
  对应磁盘上的 `miniapp/src/static/...`。
- **格式**：照片用 JPEG/WebP，需要透明背景的用 PNG。
- 「淘口令」一列指该素材对应的商品是否需要配套淘口令；淘口令本身写在数据里（见文末），不是图片。

## B. 3D 人台（功能一 §7.9、功能三 §9.5）

规格要求「半写实 3D 人台或模特，不使用卡通小人」。

建议尺寸：**200 × 1190 px**，即与现素材保持同比例（93 : 553 ≈ 1 : 5.95）；
格式 **PNG，必须透明背景**。

> ⚠️ **换素材时必须保持构图**：`components/AvatarViewer` 里的 `widthProfile` 有 9 个控制点，
> 分别对应「头顶 0 / 颈 0.13 / 肩 0.22 / 胸腰过渡 0.36 / 腰 0.45 / 胯 0.52-0.57 / 腿 0.72 / 脚 1.0」
> 这些高度比例，是照着现素材的构图量出来的。新素材如果留白更多、人物在画面里的位置变了，
> 肩腰臀的缩放会错位，需要同步调这 9 个数。最省事的做法是**新素材沿用现素材的裁切构图**：
> 头顶紧贴上边缘、脚底紧贴下边缘、人物水平居中。

> ⚠️ **现有两张素材都有问题，需要重做**：
>
> 1. `front.png` / `front-male.png` 都是**不透明矩形照片**（colorType 2，93×553，背景是薄荷→粉渐变）。
>    组件里按身形参数把人台竖切成 24 片分别横向缩放，不透明背景会让这个矩形的左右边缘产生
>    约 1px 的台阶。换成透明背景抠图后此问题自动消失，组件里的 `drop-shadow` 也才有意义。
> 2. `front-male.png` **其实是同一张女性照片，用一个棕色方块盖住头发假装短发**。
>    §7.9 要求「按性别呈现差异」，现在的性别差异实质只有肩臀系数。需要一张真的男性人台。

| 文件名 | 用途 | 目录 | 淘口令 |
|---|---|---|---|
| `front.png` | 女性人台正面 | `/static/images/model/` | 否 |
| `front-male.png` | 男性人台正面 | `/static/images/model/` | 否 |
| `back.png` | 女性人台背面（§7.9 / §9.5 背面切换） | `/static/images/model/` | 否 |
| `back-male.png` | 男性人台背面 | `/static/images/model/` | 否 |
| `outfit.png` | 搭配展示用人台（`MODEL_IMAGES.outfit`，`data/mock.ts:13`） | `/static/images/model/` | 否 |

**背面素材没到位时的现状**：`AvatarViewer` 会拿正面图镜像顶替，并在角标标注「背面演示」，
不假装是真的背面。`back.png` 到位后需要在 `pages/result/index.vue` 的 `:frames` 里把
`back` 指过去（现在两边都传的 `modelSrc`）。

## 海报底图说明

功能二的分享海报（§8.9）与功能四的场景海报（§10.10）都由 `components/OutfitPoster`
用 canvas 现场绘制，**不需要额外的底图素材**：

- 功能二：品牌渐变底 + 标题 + 真实衣物照片网格 + 日期 + 水印。
- 功能四：底图用 D 组的场景图 `/static/images/scene/<场景>.png`，叠当前滤镜，
  再画同一套衣物网格；场景图缺失时自动退回滤镜色渐变，不影响导出。

海报里的衣物照片直接取真实照片（衣橱上传图或目录图）；取不到照片的单品用该单品自己的配色画占位。

## 上传规范（§14）

- 照片：JPEG / PNG / WebP；需要叠加或去背的一律 PNG 透明背景。
- 封面比例：1:1 或 4:3。
- 视频：MP4（本轮无视频需求）。
- 单文件大小上限待云存储额度确定后再定；当前均为随包静态资源，建议单张 ≤ 200KB，
  人台图 ≤ 500KB，避免小程序主包超限。
- 缺失素材一律中性占位，禁止用卡通图替代。
