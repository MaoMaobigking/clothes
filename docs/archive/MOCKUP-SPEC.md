# 9 张设计稿 · 逐页结构规格（改版依据）

> 目标：每个页面的**布局、文字、分区、控件位置**都严格对齐设计稿。
> 图片一律用 `<TileImage :src="..." .../>`（src 取自 mock 的 img 字段），缺图自动回退占位。

## 图② 个性化创建页 → `views/CreateCenter.vue`
状态栏下方结构：
- 顶部栏：返回箭头 + 居中标题「个性化创建」+ 右上「完成」。
- 标题下一行：左上白色圆角标签「我的虚拟形象」。
- **中央**：正面全身模特图（`MODEL_IMAGES.front`，白背心+白短裤，站在**粉色椭圆台**上）。用 TileImage（ratio 约 3/4，透明底），下方加一个粉色椭圆"台子"阴影。模特右上飘一个小气泡「换发型」；膝盖附近一个「点击优化」小指示 + 圆点。
- **左侧浮层卡「基础信息」**：竖排行 身高 / 体重 / 胸围 / 大腿围 / 小腿围 / 腰围，每行右侧一个✅圆勾（勾选态）；底部粉色「保存」按钮。（沿用 CreateBasicInfo，行尾加勾选圆点样式）
- **左侧中部**：竖排 5 个测试按钮 风格测试 / 肤色测试 / 脸型测试 / 体型测试 / 偏好测试（每个带小图标），点击 → `/test`。
- **右侧竖排工具栏**：基础信息 / 更换性别 / 拍照换脸 / 造型优化 / 局部身材 / 收藏夹（AI_TOOLS），图标在上、文字在下。
- **右下**：「自由搭配 →」入口 → `/free-match`。
- **底部**：BottomNav（active=不高亮/无——该页是二级页，**保留 PageHeader，不放 BottomNav**）。注意：设计稿含底部导航，但本项目里 CreateCenter 是二级页，底部**不放** BottomNav，保持返回逻辑。

## 通用改动（所有页）
1. 凡是"图片格子"，全部改成 `<TileImage :src="实体.img" ...>`（或 ProductCard 传 `:src`），保留 from/to/emoji 作为缺图回退。
2. 文案、分区标题、tab 名称严格按上面文字。
3. 保持骨架 `.page/.body`、滚动区、按钮类、CSS 变量不变。
4. 只有 5 个 tab 主页面（Home/AiHub/Closet/Mall/Profile）放 BottomNav；其余二级页用 PageHeader + 返回。
