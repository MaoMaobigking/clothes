# 图片清单（IMAGE-MANIFEST）

把图片放进 `public/images/` 对应位置，**文件名要和下表完全一致**，页面就会自动显示。
- 没放的图会自动回退到占位（渐变色块 + emoji），所以你可以**先放重点图，其余慢慢补**。
- 建议统一用 `.png`（支持透明，衣服/首饰抠图效果最好）；用 `.jpg` 的话把下表文件名后缀改成 `.jpg` 也行，但要同步告诉我。
- 尺寸只是建议，不严格；比例尽量接近，显示更好看。
