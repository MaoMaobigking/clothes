# 面试穿搭

## 核心原则
"比日常正式半级"——不用穿成正装全套，但要体现尊重和专业。

## 按行业选择
- **互联网/科技**：Smart casual——衬衫+休闲裤+干净的运动鞋/乐福鞋
- **金融/咨询**：Business formal——西装套装+皮鞋+低调配饰
- **设计/创意**：展现品味——设计感单品+剪裁好的基础款
- **教育/公务员**：端庄得体——衬衫+及膝裙/西裤+低跟

## 必做细节
- 衣服熨平（皱褶 = 不重视）
- 指甲干净、鞋子擦干净
- 配饰低调（不戴夸张耳环/大logo）
- 提前一天准备好，避免临时手忙脚乱

## 避雷
- 牛仔裤（即使是高档的也算休闲）
- 运动鞋（设计/创意行业除外）
- 太浓香水
