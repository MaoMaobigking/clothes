# 小个子穿搭技巧

## 核心策略：优化比例
小个子穿搭的核心不是"增高"而是"优化视觉比例"，让上下身比接近 3:7 或 4:6。

## 显高技巧
- **高腰线**：所有下装选高腰款，上衣塞进裤子/裙子里
- **同色系延伸**：下装和鞋子同色，视觉上拉长腿部
- **短上衣**：衣长在肚脐以上的 crop top 或短外套
- **V领/U领**：拉长颈部线条，显脸小
- **九分裤**：露出脚踝，配浅口鞋最显腿长

## 避雷
- 过膝长裙（压个子）
- 宽松 oversize 上衣（比例失调）
- 厚底松糕鞋（笨重感反而显矮）
- 横条纹宽版（横向拉伸）

## 推荐单品
阔腿高腰裤、A字短裙、尖头平底鞋、短款牛仔外套
