# 色彩搭配基础

## 基础色轮
- **邻近色搭配**：色轮上相邻的颜色（如黄+绿），和谐柔和
- **互补色搭配**：色轮上对立的颜色（如蓝+橙），鲜明有张力
- **三角色搭配**：色轮上等距三色（如红+黄+蓝），活泼但需控制比例

## 万能配色公式
- **黑白灰**：永远不会错的基础色
- **牛仔蓝+白**：清爽减龄
- **卡其+白**：知性温柔
- **莫兰迪色系**：灰调低饱和，高级感满分
- **同色系渐变**：深浅不同的同色叠穿

## 肤色 vs 颜色
- **冷白皮**：适合粉色、蓝色、紫色、银饰
- **暖白皮**：适合橙色、黄色、金色、金饰
- **自然色**：几乎所有颜色都适合
- **小麦色**：适合白色、红色、荧光色，金饰

## 避雷
- 全身超过 3 个主色 = 杂乱
- 荧光色大面积穿 = 廉价感
- 冷暖色混搭需功力
