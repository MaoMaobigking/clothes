# 胶囊衣橱搭建指南

## 什么是胶囊衣橱
用最少的单品实现最多的搭配。通常 30-40 件（含鞋包配饰），每件都能互相搭配。

## 基础单品清单（15件）
- 上衣：白T、条纹衫、白衬衫、黑高领毛衣
- 下装：直筒牛仔裤、黑色西裤、A字裙
- 外套：风衣、西装外套、牛仔外套
- 鞋：小白鞋、黑色短靴、尖头平底鞋
- 包：黑色通勤包、帆布袋

## 搭配原则
- 所有上衣 × 所有下装都能搭配
- 中性色为主（黑白灰米蓝），每季加 2-3 个流行色单品
- 每件新买的单品至少能和已有 3 件搭配

## 节省预算
- 基础款投资好品质（风衣/大衣/包/鞋）
- 流行款买快时尚（穿一季不心疼）
- 70%基础款 + 30%流行款
