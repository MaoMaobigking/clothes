# 配饰搭配法则

## 配饰的重要性
配饰是"用最少的钱提升整体质感"的最佳方式。同一套衣服换配饰=换风格。

## 耳饰
- **脸型匹配**：圆脸→长耳坠（拉长）、长脸→圆形耳钉（加宽）、方脸→柔和曲线款、心形脸→小耳钉
- **场景**：通勤→小珍珠/金属小圈、约会→流苏长耳线、聚会→夸张几何款

## 项链
- **领口匹配**：V领→锁骨链、圆领→Y字链垂到领口下方、高领→长项链、一字肩→锁骨链
- **叠戴公式**：细锁骨链 + 中长吊坠链 + 粗链条 = 层次感

## 丝巾
- 系在颈间（代替项链）
- 系在包带上（旧包翻新）
- 当发带
- 系手腕

## 腰带
- 高腰位系腰带 = 显腿长
- 细腰带 = 女性化，粗腰带 = 帅气
- 腰链 = 配连衣裙制造腰线
