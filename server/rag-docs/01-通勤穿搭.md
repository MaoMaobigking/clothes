# 通勤穿搭指南

## 核心原则
通勤穿搭讲究"得体+舒适+不沉闷"。既要符合职场氛围，又要在空调房和室外之间自如切换。

## 基础单品
- **白衬衫**：最百搭单品，选垂感好的雪纺或棉质，避免太透
- **直筒西裤**：黑/藏蓝/卡其三色足够应对一周五天
- **西装外套**：春夏选亚麻混纺，秋冬选羊毛混纺
- **针织开衫**：比西装更柔和，内搭吊带或T恤都好看

## 配色公式
- 黑白灰经典三色打底，用丝巾/包包/鞋子跳色
- 莫兰迪色系（雾霾蓝/燕麦色/灰粉）比纯色更显高级
- 避免全身超过三个颜色

## 避雷
- 太紧身的包臀裙（不舒适且不职业）
- 露脚趾的凉鞋（多数公司不合适）
- 大面积亮片/铆钉（太浮夸）
