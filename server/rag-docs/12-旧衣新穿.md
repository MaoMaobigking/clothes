# 旧衣新穿技巧

## 核心思路
不是买新衣服，而是"用不同方式穿旧衣服"。

## 具体方法
### 改变穿搭方式
- 衬衫：单穿 → 敞开当外套 → 系在腰间 → 叠穿在针织衫里露领
- 连衣裙：单穿 → 叠穿在T恤/高领衫外面 → 配裤子穿
- T恤：单穿 → 内搭在吊带裙里 → 系结变短款

### 配饰让旧衣翻新
- 旧白衬衫 + 丝巾 = 法式优雅
- 基础款 + 腰带 = 立刻有腰线
- 素色裙 + 夸张耳环 = 聚会look
- 黑T + 金属项链叠戴 = 街头感

### 小改动
- 卷裤脚（露脚踝显瘦）
- 塞衣角（各种塞法：全塞/半塞/侧塞）
- 挽袖口（露手腕显利落）
