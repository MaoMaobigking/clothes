# 约会穿搭指南

## 根据场合选风格
- **咖啡厅/逛街**：甜美休闲风——碎花裙+针织开衫+小白鞋
- **晚餐约会**：法式优雅——小黑裙/吊带裙+西装外套+细跟
- **户外活动**：活泼元气——牛仔短裤+彩色T恤+帆布鞋
- **看电影**：舒适慵懒——阔腿裤+宽松毛衣+平底鞋

## 小心机
- 露出锁骨或手腕（适当露肤增加精致感）
- 配饰点睛：细项链、小巧耳饰、细腰带
- 喷一点淡香水（嗅觉记忆点）
- 口红选豆沙色/奶茶色（直男友好色）

## 颜色搭配
- 粉色+白色 = 甜美满分
- 红色+黑色 = 经典法式
- 香槟色+米色 = 温柔高级

## 避雷
- 第一次约会别穿太暴露
- 新鞋提前穿几次，别磨脚
- 不要太浓的妆容
