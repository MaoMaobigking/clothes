# 四季穿搭要点

## 春季
- 关键词：轻盈、明亮、层次
- 单品：风衣、针织开衫、碎花裙、小白鞋
- 配色：樱花粉/薄荷绿/鹅黄色
- 层次穿搭：薄外套+内搭，早晚温差好调节

## 夏季
- 关键词：透气、防晒、清爽
- 单品：棉麻衬衫、A字短裙、阔腿短裤、凉鞋
- 面料：棉、麻、真丝（透气吸汗）
- 防晒：轻薄防晒衫+宽檐帽+墨镜

## 秋季
- 关键词：层次、质感、温暖色
- 单品：风衣、皮衣、针织衫、切尔西靴
- 配色：焦糖色/枫叶红/橄榄绿
- 经典组合：白T+牛仔裤+风衣

## 冬季
- 关键词：保暖、叠穿、不臃肿
- 单品：羊毛大衣、高领毛衣、加绒裤、短靴
- 叠穿：保暖内衣+衬衫+毛衣+大衣
- 配色：深色为主+亮色配饰跳色
